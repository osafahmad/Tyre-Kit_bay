## Libraries shown in the app (dependency audit 2026-11-13)

Each has an entry in `LICENSE_NOTICES`. Where the licence asks for its text to travel with the app, the full text is in `src/config/licenseTexts.ts` and opens with **Show licence text**. That file is generated by `scripts/generate-license-texts.js` from the licence files shipped with the pinned packages; re-run it after updating any of them.

### TensorFlow Lite / LiteRT — Apache-2.0
- **What:** the model runtime behind `react-native-fast-tflite`: `TensorFlowLiteC` 2.17.0 with the Core ML delegate (iOS), `com.google.ai.edge.litert:litert` and `litert-gpu` 1.4.0 (Android).
- **In the app:** `Copyright The TensorFlow Authors. All rights reserved.` plus the full Apache-2.0 text.

### Google support libraries — Apache-2.0
- **What:** pulled in by ML Kit. iOS pods `GoogleDataTransport` 10.1.1, `GoogleUtilities` 8.1.5, `GTMSessionFetcher` 3.5.0, `PromisesObjC` 2.4.1, `GoogleToolboxForMac` 4.2.1; Android `com.google.android.datatransport`.
- **In the app:** `Copyright Google LLC.` plus the full Apache-2.0 text.

### Google ML Kit Text Recognition — ML Kit Terms of Service (not open source)
- **What:** Google's on-device OCR SDK, through `rn-mlkit-ocr` 0.3.1 (MIT wrapper). iOS `GoogleMLKit/TextRecognition` 9.0.0 (`MLKitCommon` 14.0.0, `MLKitVision` 10.0.0, `MLKitTextRecognition` 7.0.0, `MLKitTextRecognitionCommon` 6.0.0, `MLImage` 1.0.0-beta8); Android bundled `com.google.mlkit:text-recognition` 16.0.1, Latin only.
- **Terms:** <https://developers.google.com/ml-kit/terms>.
- **NOTICES:** the SDK ships a `NOTICES` file (`ios/Pods/MLKitCommon/NOTICES`, 1.5 MB) listing the open-source software inside its binaries. The app **references** it and does not embed it.
- **Open (owner):** decide whether a reference is enough, or whether the full file should be bundled as an asset or published with the privacy policy. The app makes no network calls, so it can't link out to it.
- **Open (owner):** ML Kit's usage metrics and store privacy answers, see DECISIONS.md "ML Kit usage metrics".

### MMKV — BSD 3-Clause, with OpenSSL and SSLeay licensed components
- **What:** `MMKVCore` 2.4.0, the storage engine behind `react-native-mmkv` 4.3.2. It compiles in OpenSSL AES code (`Core/aes/openssl`), so the OpenSSL and SSLeay acknowledgements are mandatory.
- **In the app:** `Copyright (C) 2018 THL A29 Limited, a Tencent company. All rights reserved.`, then, as their licences word them: "This product includes software developed by the OpenSSL Project for use in the OpenSSL Toolkit (http://www.openssl.org/)", "This product includes cryptographic software written by Eric Young (eay@cryptsoft.com)", "This product includes software written by Tim Hudson (tjh@cryptsoft.com)". Plus MMKV's whole `LICENSE.TXT`.
- **Store listing:** the OpenSSL and SSLeay licences ask for the same acknowledgements in advertising that mentions features or use of that software. The listing doesn't mention it; keep it that way or add the acknowledgements.

### Lucide icons — ISC, with MIT for icons derived from Feather
- **What:** `lucide-react-native` 1.68.0.
- **In the app:** `Copyright (c) 2026 Lucide Icons and Contributors`, and `Copyright (c) 2013-present Cole Bemis` for the Feather-derived icons. Plus the package's whole `LICENSE`.
